## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process token → admin decision | The elevation probe decides whether privileged phases may run — a wrong `True` grants unfettered install rights |
| config.env → machine-state checks | User-edited values (TARGET_DRIVE, MIN_FREE_GB, LINUX_USER) drive checks that can be trivially satisfied by bad input |
| external network → internet check | A remote endpoint determines pass/fail (availability/spoofing surface) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-10 | Tampering (privilege) | `:require_admin` in `_common.bat` / elevation gate in `010-preflight.bat` | mitigate | PowerShell-principal `IsInRole(Administrator)` as the ONLY classifier — cmd probes proven flaky on this machine (t4) and a flaky probe fails open. Probe output parsed exactly (`True`/`False`); anything else → not elevated (fail-closed). Asserted by `tests\verify-preflight.cmd` on both branches. |
| T-1-08 | Tampering (bypass) | preflight check ordering | mitigate | Elevation runs FIRST and any check failure exits immediately (fail-fast) — a later check can never run after an earlier failure, and no check output precedes the elevation abort (asserted). Scope-fence scan forbids `wsl`/`docker`/`bash` in 010, preventing sneak-in privileged operations. |
| T-1-09 | Spoofing | internet check target (`msftconnecttest.com`) | accept | Probe is advisory connectivity evidence, not a security control; an attacker who can spoof this endpoint owns the network already. TimeoutSec 10 bounds flakiness; message includes the URL for diagnosis. Real security gates are 050/070/090 (Phases 2-4). |
| T-1-SC | Supply chain | package installs | accept | No packages installed (in-box PowerShell/cmd only). First package surface is Phase 3 `cargo install --locked` behind its own legitimacy gate. |
