## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv → orchestrator control flow | `/from`, `/skip` values steer which code runs — malformed input crosses here |
| discovered NNN-*.bat → execution loop | Any file matching the glob in the repo root becomes executable by run-all |
| phase stdout → logs\*.log + console | Untrusted child output is captured and replayed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-04 | Spoofing | discovery glob in `000-run-all.bat` | mitigate | Strict `???-*.bat` pattern; explicit exclusion of `000` (self) and `999` (manual-only uninstall, INS-08) — a stray `abcd.bat` or `999-*.bat` can never be auto-executed (fixture-asserted, t5/t5b). |
| T-1-05 | Tampering | exit-code classification in the run loop | mitigate | Only 0=OK, 1=fatal, 3010=reboot recognized; any other rc treated as fatal (fail-closed, never fail-open); 3010 checked before `EQU 1` (t1 ≥-semantics). Asserted in verify-run-all. |
| T-1-06 | Information Disclosure | `logs\*.log` capture of phase stdout | accept | Phase contract forbids secrets in bat output (PROJECT: no secrets in bats); logs live in the user-owned repo dir, same trust level as the console itself. No log scrubber needed at this layer. |
| T-1-07 | Repudiation / replay | `/from` re-runs earlier phases | mitigate | Contract requires every phase idempotent (INS-03) — re-running a completed phase must detect "already done" and return 0; enforced per phase (010 in plan 03, later phases in their own plans), documented in run-all header comment. |
| T-1-SC | Supply chain | package installs | accept | This plan installs no packages (pure cmd + stub fixtures). Package surface begins Phase 3 behind its own gate. |
